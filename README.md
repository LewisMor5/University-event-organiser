 # CampusEvents

A website for finding and adding campus events such as sports, socials, study sessions and society showcases:
https://lewismor5.github.io/University-event-organiser/

# Features
- Browse events and see what's happening soon
- Search events by keyword
- Filter events by category
- Add a new event
- Responsive layout with a mobile navigation menu

# Built with
- HTML
- CSS
- JavaScript

## My contribution
This was a university group project. I was responsible for:
- The search bar
- Category filtering and the filtering logic
- Improving the user experience of finding events
